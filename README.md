# 沙坑切击 · Bunker Wedge

一个基于 **WebGL2 + TypeScript** 的高尔夫沙坑短杆教学游戏。沙粒按颗粒（离散元 DEM）求解，
杆头以带杆底反弹角（bounce）的刚体切进沙床，球不是被杆头直接打出，而是靠被铲起的沙粒动量带出。

## 玩法与四个页面

1. **球洞选择页** —— 3 个洞，组合干沙/湿沙、三种沙坑形状（浅碗、壶形、海滩大坑）与不同球位。
2. **沙坑击球页** —— WebGL2 3D 场景，可调五项决策：
   - 选杆（52°/56°/60°，反弹角 6°/12°/8°）
   - 站位偏移（影响下砸角）
   - 杆面打开角（越高越软）
   - 入沙点（球后方 2–12cm）
   - 挥杆力度
   并可切换正常 / 半埋 / 煎蛋（深埋）三种球位。
3. **入沙剖面慢放页** —— 2D 剖面逐颗粒回放：杆头切入、沙粒飞溅、球被沙垫带出，
   可拖拽时间轴、切换超慢/慢放/常速。
4. **成绩页** —— 本杆数据（起飞角、起飞速度、最大入沙深度、落点、顶点）、本洞记分，
   以及“同样打法在干沙 / 湿沙 / 煎蛋三种球位下”的出坑率与落点散布对比。

## 物理模型（`src/physics/`）

- `SandWorld.ts`：2D 离散元世界。颗粒间法向冲量 + 库仑摩擦 + 湿沙黏结；空间哈希加速；活动区休眠。
- **杆头**：运动学挥杆圆弧 + 一个沉浮自由度（heave）。杆底反弹角把颗粒法向反冲分解为
  向上升力——反弹角越大，杆头被“骑”上沙面，切入越浅；平板底（低 bounce）则下挖。
- **入沙点效应**：杆头在沙中推进的能量耗散在推动前方沙柱与抛洒沙粒上，入沙点离球越远，
  沙垫传递给球的动能越小，球越近。
- **球位差异**：湿沙板结（高 firmness + 黏结）使杆头易反弹、能量传递波动大；
  煎蛋球带覆盖层，需破土、效率低且弹道偏钝。
- **杆面效应**：打开杆面把动能从水平重新分配到竖直，起飞角升高、落点变近。

## 与教练说法对齐的趋势校验

```bash
npm run validate
```

无头跑数十次颗粒模拟，断言（当前 7/7 通过）：

1. 入沙点 11cm 的落点显著近于 3cm，且整体单调；
2. bounce 12° 的最大入沙深度 < bounce 6°；
3. 干沙 / 湿沙 / 煎蛋三球位出坑率明显不同；
4. 三球位落点标准差 σ 明显不同；
5. 杆面打开 24° 起飞角 > 方正、落点距离 < 方正。
